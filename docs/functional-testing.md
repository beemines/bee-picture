## 修复内容

- 登录初始化失败不再阻断公共页面；清除失效身份，修正登录返回地址与权限跳转。
- 请求体重复读取保留原始字节，修复 Windows 默认编码导致的中文和表情损坏，并支持带字符集的 JSON。
- 图片权限使用真实图片所属空间和数据库中的成员角色，忽略调用方伪造的角色及无关资源 ID。
- 权限路由使用框架实际匹配的路径，兼容路径参数和编码写法，未知路径不能继承调用方提交的空间权限。
- 团队成员的颜色检索和批量编辑按实际角色授权；禁止混入其他空间图片。
- 图片详情、缓存列表和外部识图复用有效的可见性检查，未审核公共图片限制为作者或管理员查看。
- 后台新增用户校验账号和角色，处理重复账号与重复提交。
- 编辑保存、删除及 AI 任务增加请求中的状态和错误处理；关闭弹窗后丢弃过期响应并停止本地轮询。
- 重置检索时替换完整筛选条件，切换空间时清除旧结果和权限，避免慢请求覆盖新页面。
- 分页总数按数值处理，资源 ID 保持原始精度；更新弹窗属性以匹配当前组件库。
- 替换图片保持数量不变，容量按新旧大小差额更新，保留原作者和未显式修改的元数据；并发操作通过事务和额度条件约束。
- 删除后只执行一次文件清理，保护仍被其他记录引用的原图或缩略图，正确提取当前存储域名的对象键；清理失败不再把已经提交的删除误报为失败。
- 团队管理员可按现有成员管理权限查看团队统计；公共、全空间和排行榜仍限制为全局管理员。
- 百度识图保留 URL 编码和 JSON 转义语义，增加超时与真实错误反馈，不生成替代搜索结果。

## 外部服务与边界

AI 请求未创建生成任务，无法验收结果预览及应用。需要先确认账号对模型的访问权限、地域及服务地址；[官方扩图 API](https://docs.bailian.console.aliyun.com/zh/model-studio/image-scaling-api)还规定了输入尺寸等条件。

百度网页识图接口的拒绝响应使真实检索不能通过。当前实现会如实报错；[百度正式图像搜索 API](https://ai.baidu.com/ai-doc/IMAGESEARCH/Uk3bczr77)是另一个需要鉴权的自建图库检索产品，不能直接当作该网页接口的替代。

本轮不对全部外部服务、浏览器、并发负载或生产安全作保证。已有数据若曾受替换图片计数缺陷影响，需要在备份和确认范围后单独核对；本次未对原业务库执行修复 SQL。
